# How to Create React Financial Charts of Syncfusion

A quick-start React project demonstrating Syncfusion EJ2 financial charts with title, tooltip, and crosshair examples.

## Project Overview

Minimal React sample showing how to render financial chart types and enable common UI features (title, tooltip, crosshair) using Syncfusion components.

## Features

- Simple Syncfusion EJ2 integration for React
- Example snippets for title, tooltip, and crosshair
- Links to official docs and live demos

## Prerequisites

- Node.js (LTS recommended)
- Visual Studio Code (recommended)

## Installation

1. Clone the repository.
2. Open the project in Visual Studio Code.
3. Install dependencies: `npm install`.
4. Start the app: `npm start`.

## Usage

Open the app in your browser (React dev server). Inspect `src` to see chart configuration and props used to enable title, tooltip, and crosshair.

Documentation: https://ej2.syncfusion.com/react/documentation/chart/financial-types/

Online examples: https://ej2.syncfusion.com/react/demos/#/material/chart/hilo
